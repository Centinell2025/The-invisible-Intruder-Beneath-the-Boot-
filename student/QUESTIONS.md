# Sherlock questions — 20 deterministically gradable draft prompts

All answers use the exact case-insensitive string indicated in the private instructor key. Every question is grounded in a unique evidence row; students should cite its record_id. **These are still preliminary and not yet Insane-caliber.**

1. Which host is under investigation?
2. What is the approved maintenance ticket?
3. At what UTC time does approved maintenance start?
4. Which account performs the approved logon?
5. Which OS package is approved?
6. What baseline identifier is used for Secure Boot?
7. What Secure Boot state is in the baseline?
8. What observation identifier reports the discrepant state?
9. What state is observed in OBS-017?
10. Which alert ID flags the unexpected change?
11. Which PCR index is explicitly simulated?
12. What is the measured host clock offset in seconds?
13. Which collector provides UTC reference time?
14. Which flow identifier has no TLS payload?
15. Which destination port appears in the observed network connection?
16. Which approved change scope excludes boot-policy modifications?
17. Is a verified TPM quote present (yes/no)?
18. Is malicious firmware flashing proven (yes/no)?
19. What additional TPM artifact is requested?
20. At what UTC time is the maintenance session recorded as ended?
