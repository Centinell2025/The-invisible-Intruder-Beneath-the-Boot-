# Investigation questions (draft — 20)
Each answer must cite a specific artifact and record identifier.
1. What host is under investigation?
2. What UTC date contains the triggering alert?
3. Which change ticket authorizes maintenance?
4. When did the authorized window begin?
5. Which account initiated the approved maintenance?
6. Which event first reports a boot-policy discrepancy?
7. Which source records the Secure Boot baseline?
8. What baseline Secure Boot state was documented?
9. What state was observed after maintenance?
10. Which record describes a TPM PCR observation?
11. What is the PCR index in that record?
12. Which measurement is explicitly labeled simulated?
13. What is the observed clock offset for the host?
14. What event must be time-normalized before correlation?
15. Which network connection is temporally adjacent to the alert?
16. Does that connection independently establish firmware tampering?
17. Which evidence contradicts a claim of a verified malicious firmware flash?
18. Which change was explicitly approved?
19. What conclusion is supported by the provided evidence, and at what confidence?
20. What additional acquisition would be needed to verify firmware integrity?
**Note:** These prompts are a draft; a complete Insane release requires deeper multi-source artifacts and blind playtesting.
