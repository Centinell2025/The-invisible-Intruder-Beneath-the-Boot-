# LAB-28 — False Positive

**Status:** scenario specification, not yet a playable lab. **Fictional environment:** Northbridge Systems.

## Objective
Identify a sensor parsing error that resembles boot-policy tampering.

## Evidence to build
- raw event
- parser output
- sensor version

## Student investigation
1. Confirm source integrity and provenance.
2. Normalize timestamps to UTC and correlate independent sources.
3. Identify relevant record IDs and test competing hypotheses.
4. State supported findings, uncertainties, and next acquisition steps.

## Challenge
What conclusion is supported by these artifacts, and which alternative explanation remains plausible?

## Required output
Evidence-cited timeline, confidence assessment, and recommended follow-up. Never claim a firmware compromise without verifiable acquisition. No private CoreShield material is included.
