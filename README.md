# The-invisible-Intruder-Beneath-the-Boot-
Insane-level DFIR Sherlock investigating stealthy boot compromise through Windows, UEFI, Secure Boot, and TPM evidence. Reconstruct the attack, expose hidden tampering, and identify the intruder.

## Student and reviewer instructions

- [Download the student ZIP](downloads/The_Invisible_Intruder_HTB_Student.zip). The package is password-protected; use the password provided through the authorized challenge submission.
- Read `EVIDENCE_GUIDE.md` and `QUESTIONS.md` after extraction. Validate evidence against `SHA256SUMS.txt` before solving.
- The investigation uses fictional Northbridge Systems and synthetic Windows, process, network, file-access and boot-state records. Simulated TPM or boot observations are **not** hardware attestation or proof of firmware compromise.
- Difficulty **Insane is proposed, not independently established**. The release requires an independent blind solve, unique-answer verification, and a separate confidential instructor writeup.
- See [Reviewer Guide](REVIEWER_GUIDE.md) for scope and limitations.
